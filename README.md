# Zoo Java Project

## About
This is a project containing a small zoo system providing basic reports and stats on
animals within the zoo. It allows basic add, delete and edit functions.

## Features
- View and search for specific animals within the zoo
- Add, edit and delete animals
- Reports on the animals in the zoo

## How To Use
(Tested on Intellij)
1. Download or clone the file from the repository
2. If it is a zip file, extract the contents of the zip file
3. Drag the file into your Java IDE.
4. To open the code and have it be able to run, navigate to the "src" file and find ZooMain
5. Run the program from the IDE

#### More Info: This is if loading in the animals and zoo details files already in the project folder
- Sometimes the txt files on Intellij can have issues loading. Here's the fix I found if this happens:
1. Navigate to the navigation bar and find the drop down menu to the left of the green play button
2. Select Edit Configuration and press the plus in the top left of that menu. Select application
3. Fill in the Name and Main Class as ZooMain, and select the working directory as the file with both
  the txt files and the src file which should usually be "ZooJavaProject".
4. Once selected, click apply followed by ok and run like normal. Hopefully the information should be
should be loaded in.
